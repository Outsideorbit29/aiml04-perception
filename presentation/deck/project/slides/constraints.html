Constraints

Anything that can run online runs online

Laptop · RTX 3060 Laptop, 6 GB VRAM

CARLA rendering and the models share one GPU

Runs only CARLA + ROS2, in sessions of 30 min or less

One-time TensorRT engine build; no PyTorch, no datasets

Cloud · Kaggle T4, GitHub Actions, W&B

Kaggle: data prep, training, every eval, ONNX export, benchmarks

GitHub Actions: lint and tests on every push

W&B: every metric, plus weights and ONNX files

Budget: about 30 Kaggle GPU-hours a week, and one deadline shared with a second internship project.

Time: 0:40. The constraints shaped most of the design. The laptop has a 6 GB GPU and CARLA rendering takes a large part of it, so: no PyTorch in the live loop, small “s” models, and TensorRT FP16 engines. The second constraint was laptop load. Training, every dataset evaluation, the ONNX export and the T4 benchmark ran as Kaggle jobs launched from the laptop; tests ran in GitHub Actions; every run is logged to W&B. The laptop never held the datasets. It only ran CARLA and ROS2 in short sessions, and built the TensorRT engines once, because engines only run on the GPU they were built on. Kaggle gives about 30 GPU-hours a week, so long runs had to fit one session or resume from W&B.
