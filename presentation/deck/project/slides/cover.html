The brief asked for a vision pipeline that detects lanes, vehicles and pedestrians, tracks them, estimates distance, and runs inside a driving simulator, using YOLO, OpenCV, ROS2, CARLA, TensorRT, ONNX and Weights and Biases. I built it as one Python package with no ROS or CARLA code in it. The same code runs on dataset videos in the cloud and live in CARLA, where ROS2 nodes feed it camera frames and a rule-based controller slows down or brakes. The headline: in the four scripted CARLA scenarios — a stopped car, a pedestrian crossing, a cut-in and a stopped car at night in heavy rain — the car stopped every time without a collision. Each scenario was run once for the final recording, which I come back to under limitations.
